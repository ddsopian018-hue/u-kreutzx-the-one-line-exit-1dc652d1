A one-line resignation letter from a night-shift warehouse guard: eleven years guarding $40M of stock, and the one thing that ever got stolen was his lunch — twice — by the manager. It reads like a letter a real person could actually send (job, effective date, years of service, a hard number), and the joke is a scale joke that lands in the last three words: the thief isn't a burglar, it's the boss. Short, specific, and the kind of line a colleague forwards in the group chat.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (exactly one line, 139 characters) to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset). The program validates the line against the gate (1–140 characters, exactly one line, not only whitespace) and re-reads the written file to confirm it before exiting.
